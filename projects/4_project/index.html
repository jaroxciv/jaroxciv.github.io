Agora — Self-Organization in Agent Populations

From designed coordination to emergent organization.

🏛️ Agora asks: how does decentralized resource allocation shape organization in multi-agent systems? Instead of designing roles, workflows, and routing up front, Agora lets organization emerge from an economy: agents pay to work, earn by improvement, and wealth favors future activity.

Research project from the MIT–NEU–UF Summer Camp 2026.

❓ Problem

Multi-agent LLM systems coordinate well, but their organization is designed externally: fixed roles, central routing, centrally governed resources. Organization is an input, not an outcome — each fixed piece can become a bottleneck or a single point of failure, wasting effort and losing what works.

Prior work covers pieces of this: adaptive search allocates compute but stays globally controlled; self-evolving MAS evolve roles but treat compute and survival as exogenous; agent economies coordinate via markets but do not couple scarcity, verification, and knowledge. Agora couples all three.

🌱 How It Works

Many agents search at once · one official grader decides what is better · an economy decides who keeps working · what they learn is shared.

An illustrative run: identical agents with no roles submit to the grader, pay rent, earn credit along lineage, die or reproduce, and publish to a shared culture until they differentiate. Credit is the framework's settlement; culture is its public shared state.
🧩 Framework — the full architecture
Four planes. Discovery: agents edit and test program versions on their own, for free. Truth: one sealed grader scores submissions; improvements replace the best version, the rest become evidence. Economy: live agents pay rent, richer agents get more turns, and each gain is split across its contributors; an agent dies when its wealth runs out. Shared state: work, artifacts, skills, and evidence persist in public with causal provenance.
💰 Economic selection — the equations

A closed loop: scarce resources create costs, verified contributions create wealth, and wealth biases who receives future compute.

  • Rent grows with resource use (model FLOPs, evaluations).
  • Wealth = starting wealth + share of each verified gain − rent − investment in newborns. Gains are split by causal contribution.
  • Selection: agents bid a fraction of their wealth; the next model slot goes to a wealth-weighted softmax draw.
🌱 How selection creates organization — static summary
Discovery → Truth → Causal credit → Persistence → Emergence. Two feedback loops drive it: economic (success changes who searches next) and cultural (success changes what others can build on). Identical agents with no roles become differentiated behavior, artifact-reuse pathways, and persistent lineages.

📊 Results

🔍 Findings

Organization is an outcome of search, and its form differs across tasks:

  • Selective persistence: useful knowledge can outlive the agent that created it.
  • Recombination: winning lineages span multiple authors.
  • Culture: successful lineages promote reuse.
  • Differentiation: diverse search niches emerge from identical agents.
